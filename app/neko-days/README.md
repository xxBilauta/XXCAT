# 喵日子

以圓胖橘色英國短毛貓為主題的繁體中文行事曆手帳網頁 App。

## 功能

- 行事曆、分類篩選、行程新增與編輯、完成勾選、搜尋。
- 每日手帳、心情記錄、日期貼紙。
- 健康日常：喝水量、個人目標、餐食與手動輸入的卡路里。
- 收支流水帳：新臺幣收入與支出、分類、每月結餘。
- 影像手帳：手機拍照、相簿選圖、照片預覽與刪除。
- 韓文小教室：40 個字母、30 個入門單字、自訂單字、收藏與熟悉標記、五題小測驗、每日練習紀錄。
- 含照片與學習進度的 JSON 備份匯出與匯入。
- 每月回顧：健康記錄完整度、喝水／餐食統計、收支分類與上月比較、學習天數與測驗統計、CSV 匯出及列印報表。

## 本機執行

使用 Node.js，無須安裝套件：

```sh
npm run dev
```

開啟 http://127.0.0.1:5173 。部署使用 `dist/` 靜態檔案。

文字資料儲存在 localStorage；照片儲存在 IndexedDB，影像會壓縮以節省空間。資料屬於目前瀏覽器與網站來源，沒有跨裝置雲端同步。換裝置或清除瀏覽器資料前，請先匯出備份。手機拍照由瀏覽器和作業系統提供的相機選取器處理。

行事曆初始內容是可清除的範例；健康、收支和照片以空白開始。

韓文學習入口：手機底部「更多 → 韓文小教室」。練習按臺北當日累積；同一天重複練習相同項目不重複計入每日五項目標。朗讀使用瀏覽器提供的韓語語音；裝置沒有韓語語音時會提示。此版不使用付費翻譯或 AI 服務。

驗證：`node --test tests/*.test.mjs`。
